## 📌 About This Repository

The purpose of this repository is to maintain and share Machine Learning practical implementations in an organized manner.

- Practical codes and implementations.
- Practice notebooks and solution notebooks.
- Supporting training datasets.
- Experiments covering different Machine Learning techniques.
- Implementations primarily developed using Google Colaboratory.

The codes have been written and checked for corrections. Students are encouraged to practise the implementations using other suitable IDEs and development environments.

## 💻 How to Use This Repository

1. Clone or download this repository.
2. Open the `Experiments` directory.
3. Select the experiment you want to practise.
4. Open the corresponding Practice or Solution notebook.
5. Download the required dataset if necessary.
6. Execute the notebook using Google Colab or Jupyter Notebook.

### Clone Repository

```bash
git clone https://github.com/Trinitykhuman/Machine-Learning-practical.git
```
